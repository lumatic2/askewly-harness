# session-log

세션을 **저널에 append만** 하고 끝낸다. `session-end` 의 경량 버전 — 여러 세션이 같은 레포에서 동시에 일할 때 `ROADMAP.md`·`HANDOFF.md` 를 서로 덮어쓰지 않도록 저널만 누적한다.

## 하지 않는 것

레포 파일을 **하나도** 수정하지 않는다 — ROADMAP·HANDOFF.md·CLAUDE.local.md·CLAUDE.md·README 편집, git commit, 배포, 저널 daily log 외 노트 생성 전부 금지. 그게 필요하면 `session-end`(전체 마감)·`/harness-done`(ROADMAP)·`저널-write`(노트)를 쓴다.

## 실행

레포 파일은 필요한 만큼만 읽고, 본문을 stdin 으로 헬퍼에 넘긴다. 헬퍼가 날짜·기기 레이블·파일명·헤더·append 를 처리한다. 기록 위치는 `$HARNESS_JOURNAL_DIR`.

```bash
PYTHONIOENCODING=utf-8 python3 ~/.claude/skills/session-log/bin/session-log.py <<'BODY'
한 줄 요약
  {무엇이 실제로 바뀌었는지 한 문장}

한 일 / 증거
  - {한 항목에 작업 + 근거를 같이. 커밋 해시·경로·검증 결과·before/after 가 있으면 그 항목에 붙인다}
  - {같은 사실을 작업과 증거로 나눠 두 번 쓰지 않는다}

판단 / 배운 것
  {왜 A 대신 B 였는지, 문서·코드가 실제와 달랐던 점, 재사용 가능한 지식.
   이력서 문장으로 번역 가능한 사실도 여기 — 평가가 아니라 행동·숫자·결과로. 없으면 섹션 생략}

막힌 것 / 개선할 것
  - 막힌 것: {미해결 문제 — 시도한 것 + 왜 안 됐는지}
  - 개선할 것: {이번 산출물을 /pr-review 축으로 자기점검 — spec(요구·계획 대비 누락) / quality(정확성·유지보수성·보안·테스트 공백)}
  둘 다 없으면 섹션 생략
BODY
```

Codex 에서 위 경로가 없고 repo-local 스킬 디렉터리에서 실행 중이면 `python3 session-log/bin/session-log.py` 로 대체한다.

## 작성 기준

- **필수는 앞 2개 섹션**(`한 줄 요약`·`한 일 / 증거`). 뒤 2개는 내용이 있을 때만 쓴다 — 채우려고 늘리지 않는다.
- **적을 것**: 나중에 근거가 될 사실(커밋·숫자·before/after), 판단과 그 이유, 비자명한 발견(drift·함정).
- **뺄 것**: 자명한 과정 나열("파일 읽음"·"grep 함"), 결과 없는 도구 사용 절차, 커밋 메시지·diff 에 이미 남는 내용의 재진술.
- **길이는 세션의 증거량에 맞춘다.** 별일 없으면 5줄로 끝내도 된다.
- 판정 기준 = "나중에 이 로그만 보고 무엇을 했고 어떤 증거가 남았는지 복원 가능한가".

## 출력

**헬퍼가 stdout 으로 기록물을 되돌려 주지만, bash 출력은 사용자 화면에 보이지 않는다.** 따라서 `── 기록한 세션 … ──` 블록부터 `✓ … 기록 완료 (append)` 줄까지를 **최종 답변 본문에 직접 출력해야** 사용자가 무엇이 기록됐는지 볼 수 있다. "기록했다"는 요약으로 대체하면 사용자는 아무것도 못 본다.

헬퍼 stdout 을 그대로 옮긴다 — 재타이핑하면 기록물과 어긋난다. 기록 블록을 완료 문장보다 **먼저** 출력하고, 마지막에 이 문장을 붙인다.

```text
저널 기록 완료 (append only)
```
